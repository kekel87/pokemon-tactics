# Prototypes de la carte du monde

Scripts et données produites par nous pour les prototypes de la carte du mode Aventure, sans aucune image : les
images, calques et sources non libres restent hors git dans `assets-src/references/aventure/` (même arborescence).

Chaque itération, sa commande et les retours de l'humain : graphe, `journal-iterations-carte-du-monde` ; état,
méthode et leçons : `methode-carte-du-monde-lecons-des-iterations`. Les sources se retéléchargent depuis les adresses
notées dans ces entrées (dépôts pret, Natural Earth, tuiles Terrarium d'AWS, Bulbagarden Archives).
